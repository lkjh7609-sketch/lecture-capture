# 수업캡처

수업 중에는 켜 두기만 한다. 끝나면 "정리 만들기"를 누르면 `페이지_…html`과 `강의노트_…pdf`가 나온다.

## 설치 (Windows 노트북, 한 번만)
노트북에는 아무것도 미리 깔 필요가 없다. Python도 필요 없다(설치 파일 안에 다 들어 있음).

1. GitHub 공개 저장소 [lkjh7609-sketch/lecture-capture](https://github.com/lkjh7609-sketch/lecture-capture) → **Actions** → "수업캡처 설치 파일" → 맨 위(최신) 실행 → 아래 **Artifacts**의 `LectureCapture-Setup` 다운로드 → 압축 풀기.
2. `LectureCapture-Setup-1.0.0.exe` 더블클릭. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**(서명 안 된 개인 프로그램이라 뜨는 경고).
3. 설치 화면에서 **"Claude Code 설치"** 체크(기본 켜짐). Git for Windows와 Claude Code를 자동으로 설치한다. 인터넷 필요.
4. 설치가 끝나면 수업캡처가 실행된다.
   - **작업 폴더**: "예"를 누르면 `문서\수업정리` 폴더를 새로 만든다(템플릿 자동 복사). 이미 SAPCODE1 폴더가 있으면 "아니오"를 누르고 고른다. 한 번만 하면 기억한다.
   - **[Claude 로그인]** 버튼 → 검은 창에서 안내대로 로그인(처음 한 번). 로그인이 끝나면 창을 닫는다.
5. 한국어 OCR이 없으면 설치한다(선택): 설정 → 시간 및 언어 → 언어 → 한국어 → 언어 옵션 → 광학 문자 인식.
6. 처음 녹음할 때 받아쓰기 모델(약 500MB)을 한 번 내려받는다(인터넷 필요).

PDF는 설치 파일에 들어 있는 `lctool.exe`(Python 대용)와 Windows 기본 브라우저 Edge로 만든다.

### 설치 파일 다시 만들기(개발용)
`tools/수업캡처/` 아래를 고친 뒤 `python tools/수업캡처/publish_public.py <lecture-capture 폴더>`로 공개 저장소에 반영하고 push하면 Actions가 새 설치 파일을 만든다(SAPCODE1은 비공개라 결제 문제로 Actions가 막혀 있음). Windows PC에서 직접 만들려면 Python 3.12와 Inno Setup(`winget install JRSoftware.InnoSetup`)을 깔고 `build_installer.bat`.

## 수업 날
0. 녹화를 시작할 때 디스코드가 일반 모드면 "가림방지 모드로 다시 실행할까요?"라고 물어본다. 예를 누르고 방송에 다시 들어간다(하루 한 번).
1. 디스코드 방송을 켜고 앱의 **영역 지정**을 누른다 → 찍기 → 방송 화면만 드래그 → 저장. 한 번 저장하면 다음부터는 생략해도 된다.
2. **시작**을 누른다.
   - 화면이 바뀌면 자동으로 저장한다. 같은 화면에 펜 필기나 코드가 추가되면 그 모습도 저장한다.
   - `Shift+Z`: 지금 화면을 ★로 저장한다(삑 소리).
   - `Shift+X`: 메모 창. Enter로 저장, Esc로 취소.
   - 녹화 중에는 대문자 Z/X를 칠 수 없다. 타자가 필요하면 트레이 메뉴의 "단축키 일시정지"를 쓴다.
   - 디스코드는 **최소화해도 된다.** 녹화 중에는 앱이 최소화를 가로채 디스코드를 모든 창 맨 뒤로 숨긴다(최소화된 창은 Windows가 그리지 않아 캡처할 수 없기 때문). 끄려면 "최소화 가로채기" 체크를 해제한다.
   - 점심시간에는 **정지**를 누른다. 남은 받아쓰기·다듬기·글 옮기기를 그동안 처리한다. 다시 **시작**하면 같은 날 폴더에 이어서 기록한다.
3. 수업이 끝나면 **정리 만들기**를 누른다. 남은 받아쓰기와 다듬기를 마친 뒤 `/ln`가 실행되고, 끝나면 HTML이 열린다.

## 데이터 흐름
```
디스코드 창 ─2초마다─▶ 변화 감지 ─▶ 캡처/날짜/shots/*.png ─▶ Windows OCR
                                     └─20장/1시간마다─▶ claude -p Opus가 글로 옮김(notes.jsonl)
노트북 마이크 ─5분 조각─▶ whisper 초안 ─▶ (wav 삭제) ─▶ 15분씩 묶어 claude -p Haiku로 다듬기
Shift+X 메모 ─────────────────────────────────────────────┐
                                     timeline.md ◀────────┘ 시간순 병합
                                          │
                              claude -p "/ln …timeline.md DAY 날짜"
```

## 저장 판정 (detect.py)
| 경우 | 동작 |
|---|---|
| 슬라이드·화면 전환(픽셀 12% 이상 변화) | 화면이 3초 멈추면 바로 저장 |
| 펜 필기·코드 줄 추가(커서보다 큰 변화) | 20초에 한 장까지. 그 사이 변화는 들고 있다가 화면이 넘어가기 직전에 마지막 모습으로 저장 |
| 마우스 커서 이동, 영상 노이즈 | 무시 |
| 검은 화면(방송 끊김) | 무시 |

값은 `config.json`에서 조정한다(`major_diff`, `minor_cells`, `min_gap_sec`, `stable_sec`).

## 노트북 리허설 체크리스트 (Mac에서는 확인 불가)
1. **가림방지 전달**: "디스코드 가림방지 실행" → 방송 재입장 → 정지 → 시작. 다시 묻지 않아야 정상이다. 다시 물으면 옵션이 디스코드에 전달되지 않은 것이다.
2. **가려진 채 캡처**: 디스코드를 다른 창으로 30초 이상 완전히 덮은 상태에서 강사 화면이 바뀔 때 새 캡처가 생기는지 본다.
3. **최소화 가로채기**: 디스코드 최대화 → 시작 → 최소화. 맨 뒤로 숨고, 크기가 그대로이고, 영역이 맞는지 `캡처/날짜/shots` 최신 이미지로 확인한다.
4. **창 크기 변경**: 실습 중 디스코드를 반 화면으로 붙이면 영역이 어긋난다. 로그에 "창 크기가 영역 지정 때와 다름"이 뜬다.
5. 단축키 Shift+Z/X, OCR, 녹음 10분 → 받아쓰기·다듬기 → 정리 만들기 → HTML/PDF가 열리는지.

## 8시간 수업 부하 대응
| 항목 | 방법 |
|---|---|
| whisper가 CPU를 많이 씀 | "받아쓰기: 정지 후"로 바꾸면 녹화 중에는 녹음만 하고, 점심·종료 후에 받아쓴다 |
| 다듬기 호출 수 | 15분씩 묶고 짧은 시스템 프롬프트를 써서 하루 약 32번 |
| 이미지 수백 장 | 수업 중에 20장(또는 1시간)마다 Opus가 미리 글로 옮겨 둔다. 마지막 정리는 그 글을 읽고, 이미지는 ★만 본다. 사용량이 가장 많은 항목이다(`notes_model`로 변경 가능) |

## 파일
| 파일 | 역할 |
|---|---|
| `app.py` | 창, 트레이, 단축키, 흐름 제어 |
| `capture.py` / `winapi.py` | 디스코드 창 캡처(PrintWindow → 안 되면 화면 캡처) |
| `detect.py` | 변화 감지. `python detect.py 이미지들…`로 판정 테스트 |
| `ocr.py` | Windows 내장 OCR |
| `audio.py` | 녹음, whisper 받아쓰기, wav 삭제 |
| `refine.py` | 받아쓰기 다듬기(claude -p Haiku, 15분 묶음) |
| `notes.py` | 캡처를 글로 옮기기(claude -p Opus, 20장 묶음) |
| `discord.py` | 디스코드 가림방지 옵션 재실행 |
| `timeline.py` | 세션 → timeline.md. `python timeline.py 캡처/날짜` |
| `runner.py` | /ln(수업정리) 실행 |
| `installer.iss` / `build_exe.bat` / `build_installer.bat` / `make_icon.py` | 설치 파일 빌드(PyInstaller + Inno Setup) |
| `lctool.py` | Python 없는 노트북에서 `_template/*.py` 실행(pymupdf 포함) |
| `config.json` | 사용자 설정(처음 저장할 때 생김) |
